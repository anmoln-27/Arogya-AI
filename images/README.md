# 📂 Images — README & Documentation Assets

This directory contains **image assets** used in the project README and documentation.

## Usage

Reference images in markdown files using relative paths:

```markdown
![Description](images/your-image.png)
```

## Guidelines

- Use **PNG** format for diagrams and screenshots
- Use **JPG** for photos of hardware
- Keep file sizes reasonable (compress if > 1 MB)
- Use descriptive filenames (e.g., `system_block_diagram.png`, not `img1.png`)
